## 1. Phân loại lỗi chương trình

<GlassCard title="3 loại lỗi chính">
**1️⃣ Lỗi Cú pháp (Syntax Error)**
- Viết sai luật của ngôn ngữ Python. Chương trình **không chạy được**.

**2️⃣ Lỗi Runtime (Exceptions Error)**
- Cú pháp đúng nhưng gặp lỗi **khi đang chạy** (ví dụ: chia cho 0).

**3️⃣ Lỗi Logic (Logic Error)**
- Chương trình chạy bình thường nhưng **kết quả sai**. Khó tìm nhất!
</GlassCard>

---

## 2. Lỗi Syntax Error (Lỗi cú pháp)

<Alert type="warning">
**Đặc điểm:** Python sẽ báo lỗi **ngay lập tức** và không cho phép chương trình bắt đầu chạy.
</Alert>

### Ví dụ thường gặp

```python
# ❌ SAI - Thiếu dấu :
while True print("Hello")
# SyntaxError: invalid syntax

# ✅ ĐÚNG
while True:
    print("Hello")
```

```python
# ❌ SAI - Thiếu )
x = int(input("Nhập x: ")
# SyntaxError: unexpected EOF while parsing
```

---

## 3. Lỗi Runtime (Exceptions Error)

<Alert type="danger">
**Đặc điểm:** Chương trình chạy được một lúc rồi **dừng đột ngột**. Python báo mã lỗi (Exception).
</Alert>

### Ví dụ: IndexError

```python
A = [1, 3, 10, 0]

for i in range(5):      # i chạy từ 0 đến 4
    print(A[i], end=" ")

# Kết quả: 1 3 10 0 
# IndexError: list index out of range (Vì A[4] không tồn tại)
```

### Các mã lỗi Runtime phổ biến

| Mã lỗi | Nguyên nhân | Ví dụ |
|--------|-------------|-------|
| `ZeroDivisionError` | Chia cho 0 | `10 / 0` |
| `IndexError` | Chỉ số vượt quá | `A[100]` |
| `TypeError` | Sai kiểu dữ liệu | `"10" + 5` |
| `ValueError` | Giá trị không hợp lệ | `int("abc")` |
| `NameError` | Biến chưa khai báo | `print(x)` |

## 4. Lỗi Logic (Logic Error)

<Alert type="info">
**Đặc điểm:** Chương trình chạy xong xuôi, không báo lỗi gì nhưng **kết quả không như mong đợi**.
</Alert>

```python
# Bài toán: Tính tổng 1+2+3+...+10 (Đúng ra phải = 55)

S = 0
for i in range(10):      # SAI: range(10) chỉ chạy từ 0→9
    S = S + i

print(S)                 # In ra 45 (LỖI LOGIC!)
```

## 5. Kỹ năng đọc thông báo lỗi 📖

<GlassCard title="Cách đọc thông báo lỗi">
**Đọc từ DƯỚI lên TRÊN:**
1. **Dòng cuối cùng:** Cho biết loại lỗi (ví dụ: `ZeroDivisionError`).
2. **Dòng phía trên:** Cho biết dòng code nào gây lỗi.
3. **Traceback:** Theo dõi hành trình của lỗi qua các hàm.
</GlassCard>

## Thực hành

### Nhiệm vụ 1: Tìm và sửa lỗi

```python
# Code lỗi
n = int(input("Nhập n: ")
S = 0
for i in range(n):
    S = S + i
print("Tổng =", S)
```

<details>
<summary>💡 Xem đáp án sửa lỗi</summary>
```python
n = int(input("Nhập n: "))      # (1) Thiếu đóng ngoặc
S = 0
for i in range(1, n+1):         # (2) Logic: cần đến n
    S = S + i
print("Tổng =", S)
```
</details>
