## 1. Các lệnh vào ra đơn giản

### Review nhanh: Lệnh `print()` - OUTPUT

<GlassCard title="print() - Đưa dữ liệu RA màn hình">
**Cú pháp:**
```python
print(value1, value2, ..., valueN)
```
**Đặc điểm:**
- Xuất nhiều giá trị cùng lúc (tự động thêm dấu cách)
- Tự động xuống dòng sau khi in
- Có thể in cả biểu thức (Python tự tính)

**Ví dụ:**
```python
>>> print("Xin chào", "Python!")
Xin chào Python!

>>> x = 10
>>> print("Giá trị x là:", x)
Giá trị x là: 10

>>> print("5 + 3 =", 5 + 3)
5 + 3 = 8
```
</GlassCard>

### Lệnh `input()` - INPUT 🎤

Đây là "vũ khí" mới - cho phép chương trình "lắng nghe" người dùng!


```python
# Cú pháp cơ bản
# input(<thông_báo_gợi_ý>)

# Ví dụ
>>> input("Nhập một số: ")
Nhập một số: 12
'12'

# Lưu giá trị nhập vào biến
name = input("Nhập tên bạn: ")
# Nhập tên bạn: An
print("Xin chào", name)
# Xin chào An
```


<Alert type="warning">
**Cực kỳ quan trọng:** 
Lệnh `input()` **LUÔN** trả về **xâu kí tự** (string), dù bạn nhập số!
```python
>>> x = input("Nhập số: ")
Nhập số: 100
>>> type(x)
<class 'str'>         # x là xâu "100", không phải số 100!
```
</Alert>

### Ví dụ thực tế với `input()`


```python
# Chương trình chào hỏi
name = input("Nhập họ tên em: ")
print("Xin chào", name)
print("Chúc bạn học Python vui vẻ! 🎉")

# Kết quả khi chạy:
# Nhập họ tên em: Nguyễn Văn A
# Xin chào Nguyễn Văn A
# Chúc bạn học Python vui vẻ! 🎉
```


<GlassCard title="Tổng kết Input/Output">
**`input(prompt)`** - Nhập VÀO
- Nhận dữ liệu từ bàn phím
- Hiển thị thông báo `prompt` (tuỳ chọn)
- **Kết quả luôn là xâu kí tự**

**`print(value1, value2, ...)`** - Xuất RA
- Đưa dữ liệu ra màn hình
- In nhiều giá trị cùng lúc
- Tự động thêm dấu cách và xuống dòng
</GlassCard>

## 2. Chuyển đổi kiểu dữ liệu

### Nhận biết kiểu dữ liệu với `type()`


```python
>>> n, x, s = 10, 1.8, "One"

>>> type(n)
<class 'int'>          # Số nguyên (integer)

>>> type(x)
<class 'float'>        # Số thực (floating point)

>>> type(s)
<class 'str'>          # Xâu kí tự (string)
```


### Kiểu dữ liệu Boolean (Logic)
Ngoài số và xâu, còn có kiểu `bool` - chỉ có 2 giá trị: `True` hoặc `False`.


```python
>>> 3 > 2
True

>>> 5 < 0
False

>>> b = 10 > 3
>>> type(b)
<class 'bool'>

>>> print(b)
True
```


<GlassCard title="4 kiểu dữ liệu cơ bản của Python">
| Kiểu | Tên Python | Ví dụ | Dùng để |
|------|-----------|-------|---------|
| Số nguyên | `int` | `10`, `-5`, `0` | Đếm, chỉ số |
| Số thực | `float` | `3.14`, `-0.5` | Tính toán chính xác |
| Xâu kí tự | `str` | `"Hello"`, `'123'` | Văn bản |
| Logic | `bool` | `True`, `False` | Điều kiện |
</GlassCard>

### Hàm chuyển đổi kiểu

Đây là phần **cực kỳ quan trọng** khi làm việc với `input()`!

#### `int()` - Chuyển sang số nguyên


```python
>>> int("123")        # Xâu → Số nguyên
123

>>> int(45.9)         # Số thực → Số nguyên (bỏ phần lẻ)
45

>>> int("1.5")        # ❌ Không chuyển trực tiếp được!
ValueError: invalid literal for int()

# Phải chuyển qua float trước
>>> int(float("1.5"))
1
```


#### `float()` - Chuyển sang số thực


```python
>>> float("3.14")     # Xâu → Số thực
3.14

>>> float(10)         # Số nguyên → Số thực
10.0

>>> float("15")       # Xâu số nguyên → Số thực
15.0
```


#### `str()` - Chuyển sang xâu kí tự


```python
>>> str(150)          # Số → Xâu
'150'

>>> str(3.14)         # Số thực → Xâu
'3.14'

>>> str(True)         # Boolean → Xâu
'True'
```


<Alert type="warning">
**Lỗi thường gặp:**
```python
# ❌ Không chuyển được biểu thức trong xâu
>>> int("12+45")
ValueError: invalid literal for int()
```
✅ Phải tính trước, hoặc dùng `eval()` (nhưng không nên dùng eval nếu không cần thiết).
```python
>>> 12 + 45
57
```
</Alert>

### Nhập số từ bàn phím - Kỹ năng quan trọng!

Vì `input()` trả về xâu, nên nhập số phải chuyển đổi:


```python
# ❌ SAI - Nhập số nhưng không chuyển đổi
>>> n = input("Nhập số: ")
Nhập số: 10
>>> n + 5
TypeError: can only concatenate str to str

# ✅ ĐÚNG - Nhập số nguyên
>>> n = int(input("Nhập số tự nhiên: "))
Nhập số tự nhiên: 13
>>> n + 5
18

# ✅ ĐÚNG - Nhập số thực
>>> x = float(input("Nhập số thực x: "))
Nhập số thực x: 3.14
>>> x * 2
6.28
```


<GlassCard title="Pattern nhập số - Học thuộc lòng! 📌">
```python
# Nhập số nguyên
bien_nguyen = int(input("Thông báo: "))

# Nhập số thực
bien_thuc = float(input("Thông báo: "))

# Nhập xâu (không cần chuyển)
bien_xau = input("Thông báo: ")
```

**Công thức vàng:**
- Cần số nguyên → `int(input(...))`
- Cần số thực → `float(input(...))`
- Cần xâu → `input(...)` (không cần gì thêm)
</GlassCard>

## Thực hành

### Nhiệm vụ 1: Tính tổng 3 số
Viết chương trình nhập 3 số nguyên `m`, `n`, `p` rồi in tổng.


```python
# Nhập từng số
m = int(input("Nhập số nguyên m: "))
n = int(input("Nhập số nguyên n: "))
p = int(input("Nhập số nguyên p: "))

# Tính và in tổng
print("Tổng ba số đã nhập là", m + n + p)

# Kết quả khi chạy:
# Nhập số nguyên m: 5
# Nhập số nguyên n: 10
# Nhập số nguyên p: 3
# Tổng ba số đã nhập là 18
```


<Alert type="success">
**Pro tip:** Có thể viết gọn hơn:
```python
tong = int(input("Nhập m: ")) + int(input("Nhập n: ")) + int(input("Nhập p: "))
print("Tổng:", tong)
```
</Alert>

### Nhiệm vụ 2: Thông tin học sinh
Nhập họ tên và tuổi, rồi in thông báo.


```python
# Nhập dữ liệu
ten = input("Nhập họ tên học sinh: ")
tuoi = int(input("Nhập tuổi: "))

# In thông tin
print("Bạn", ten, tuoi, "tuổi")

# Hoặc dùng f-string (Python 3.6+) - hiện đại hơn:
print(f"Bạn {ten} {tuoi} tuổi")

# Kết quả:
# Nhập họ tên học sinh: Nguyễn Hoà Bình
# Nhập tuổi: 15
# Bạn Nguyễn Hoà Bình 15 tuổi
```


<Alert type="info">
**f-string là gì?**
- Cách format xâu hiện đại của Python
- Cho phép nhúng biến trực tiếp vào xâu
- Cú pháp: `f"text {bien} text"`
```python
name = "An"
age = 16
print(f"Tôi là {name}, {age} tuổi")  # Gọn và dễ đọc!
```
</Alert>

- b) OK - Số thực sang số thực (không đổi gì)
- c) Lỗi - Xâu không đúng format số (có dấu phẩy lạ)

### Bài 2: Giải thích
Tại sao nhập số thực phải viết `float(input())`?

<details>
<summary>💡 Xem đáp án</summary>

Vì `input()` luôn trả về xâu kí tự.
Nếu chỉ viết `input()`:
```python
x = input("Nhập số: ")    # x = "3.14" (xâu)
y = x * 2                 # y = "3.143.14" (lặp xâu!)
```
Phải chuyển sang float:
```python
x = float(input("Nhập số: "))  # x = 3.14 (số)
y = x * 2                      # y = 6.28 (đúng!)
```
</details>

### Challenge 1: Đổi giây sang ngày-giờ-phút-giây (có input)

# Nhập số giây từ bàn phím
ss = int(input("Nhập số giây: "))

ngay = ss // 86400

gio = ss // 3600

### Challenge 2: Tính diện tích tam giác (Công thức Heron)


```python
# Nhập 3 cạnh tam giác
print("Nhập độ dài 3 cạnh tam giác:")
a = float(input("Cạnh a: "))
b = float(input("Cạnh b: "))
c = float(input("Cạnh c: "))

# Tính nửa chu vi
p = (a + b + c) / 2

# Tính diện tích (công thức Heron)
S = (p * (p - a) * (p - b) * (p - c)) ** 0.5

# In kết quả
print(f"Chu vi: {a + b + c}")
print(f"Diện tích: {S:.2f}")  # Làm tròn 2 chữ số thập phân
```


<Alert type="info">
**Công thức Heron:**
- Nửa chu vi: `p = (a+b+c)/2`
- Diện tích: `S = √[p(p-a)(p-b)(p-c)]`
- Trong Python: `**0.5` = căn bậc 2
</Alert>

## Bảng tóm tắt các hàm quan trọng

<GlassCard title="Cheat Sheet - Học thuộc! 📝">
| Hàm | Công dụng | Ví dụ |
|-----|-----------|-------|
| `input(prompt)` | Nhập từ bàn phím | `name = input("Tên: ")` |
| `print(value, ...)` | In ra màn hình | `print("Hello", name)` |
| `int(x)` | Chuyển → số nguyên | `int("123")` → `123` |
| `float(x)` | Chuyển → số thực | `float("3.14")` → `3.14` |
| `str(x)` | Chuyển → xâu | `str(100)` → `"100"` |
| `type(x)` | Kiểm tra kiểu | `type(5)` → `<class 'int'>` |

**Pattern nhập số:**
```python
# Số nguyên
n = int(input("..."))

# Số thực  
x = float(input("..."))

# Xâu
s = input("...")
```
</GlassCard>

## Tổng kết

<GlassCard title="Key Takeaways 🔑">
**1. Input/Output**
- `input()` - Nhập VÀO từ bàn phím (kết quả là xâu)
- `print()` - Xuất RA màn hình

**2. Kiểu dữ liệu cơ bản**
- `int` - Số nguyên
- `float` - Số thực
- `str` - Xâu kí tự
- `bool` - Logic (`True`/`False`)

**3. Chuyển đổi kiểu**
- `int()` - Chuyển sang số nguyên
- `float()` - Chuyển sang số thực
- `str()` - Chuyển sang xâu
- `type()` - Kiểm tra kiểu

**4. Quy tắc vàng khi nhập số**
```python
# Luôn chuyển đổi kiểu!
number = int(input("..."))      # Số nguyên
decimal = float(input("..."))   # Số thực
```
</GlassCard>

### Bonus: Tricks nâng cao ✨

**1. Nhập nhiều số trên cùng 1 dòng**

```python
# Nhập: "10 20 30" (cách nhau bởi dấu cách)
numbers = input("Nhập 3 số: ").split()
a, b, c = int(numbers[0]), int(numbers[1]), int(numbers[2])

# Hoặc gọn hơn:
a, b, c = map(int, input("Nhập 3 số: ").split())
print(a, b, c)
```


**2. Format output đẹp hơn**

```python
# Làm tròn số thập phân
pi = 3.14159265
print(f"Pi = {pi:.2f}")      # Pi = 3.14

# Căn lề
name = "Python"
print(f"{name:>10}")         # "    Python" (căn phải)
print(f"{name:<10}")         # "Python    " (căn trái)
print(f"{name:^10}")         # "  Python  " (căn giữa)
```
