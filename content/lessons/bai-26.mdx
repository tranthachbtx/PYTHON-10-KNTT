```python
# ✅ Dùng hàm - Định nghĩa 1 lần, dùng mãi mãi!
def dien_tich_hinh_tron(r):
    pi = 3.14
    return pi * r * r

# Gọi hàm siêu gọn
print(dien_tich_hinh_tron(5))
print(dien_tich_hinh_tron(10))
print(dien_tich_hinh_tron(7))
```

## 1. Các hàm thiết kế sẵn (Built-in Functions)

Thực ra bạn đã dùng rất nhiều "hàm" từ đầu đến giờ! 🤓

<GlassCard title="Hàm có sẵn phổ biến 📋">
| Hàm | Chức năng | Ví dụ |
|-----|-----------|-------|
| `print()` | In dữ liệu ra màn hình | `print("Hello")` |
| `input()` | Nhận dữ liệu từ bàn phím | `input("Nhập tên: ")` |
| `len()` | Tính độ dài (List, String) | `len([1,2,3])` → `3` |
| `abs()` | Lấy giá trị tuyệt đối | `abs(-5)` → `5` |
| `round()` | Làm tròn số | `round(3.7)` → `4` |
| `max()` / `min()` | Tìm giá trị lớn nhất / nhỏ nhất | `max(1,5,3)` → `5` |
</GlassCard>

## 2. Tự định nghĩa hàm (User-defined functions)

### Cú pháp cơ bản

<GlassCard title="Cách tạo hàm">
```python
def tên_hàm(tham_số):
    # Khối lệnh xử lý
    return giá_trị_trả_về (nếu có)
```

**Lưu ý:**
- Bắt đầu bằng từ khóa `def`.
- Tên hàm không được có dấu cách.
- Khối lệnh phải **thụt lề** vào trong.
</GlassCard>

### Ví dụ: Hàm chào hỏi

```python
def xin_chao(ten):
    print("Xin chào " + ten + "!")
    print("Chúc bạn một ngày học Python vui vẻ! ✨")

# Gọi hàm
xin_chao("An")
xin_chao("Bình")
```

## 3. Hàm có giá trị trả về và không có giá trị trả về

### Hàm có `return`
Dùng khi bạn muốn lấy kết quả từ hàm để tính toán tiếp.


```python
def tinh_tong(a, b):
    return a + b

ket_qua = tinh_tong(5, 7)
print(ket_qua * 2) # Lấy kết quả nhân 2 -> 24
```


### Hàm không có `return` (hoặc return None)
Dùng khi bạn chỉ muốn thực hiện một hành động (như in ra màn hình).

<Alert type="warning">
**Phân biệt print() và return:**
- `print()` chỉ giúp bạn **thấy** kết quả trên màn hình.
- `return` giúp chương trình **nhận** được kết quả để làm việc tiếp.
</Alert>

## 4. Hàm kiểm tra số nguyên tố (Ví dụ Pro!)

Hãy xem cách dùng hàm giúp code logic trở nên cực kì sáng sủa:


```python
def la_so_nguyen_to(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

# Sử dụng hàm để lọc danh sách
numbers = [2, 3, 4, 5, 6, 7, 8, 9, 10]
primes = [x for x in numbers if la_so_nguyen_to(x)]

print("Các số nguyên tố:", primes)
# Output: [2, 3, 5, 7]
```


<Alert type="success">
**Tái sử dụng code:** Bạn chỉ cần viết logic kiểm tra SNT **một lần** duy nhất trong hàm `la_so_nguyen_to`, sau đó có thể dùng ở bất kì đâu trong chương trình!
</Alert>

## Thực hành

**Nhiệm vụ: Viết hàm tính giai thừa của n (n!)**


```python
def giai_thua(n):
    ket_qua = 1
    for i in range(1, n + 1):
        ket_qua *= i
    return ket_qua

# Test
n = int(input("Nhập n: "))
print(f"{n}! = {giai_thua(n)}")
```

## Luyện tập

**Bài 1: Hàm tìm số lớn nhất**
Viết hàm `tim_max(a, b, c)` nhận vào 3 số và trả về số lớn nhất.

<details>
<summary>💡 Xem gợi ý</summary>

```python
def tim_max(a, b, c):
    m = a
    if b > m: m = b
    if c > m: m = c
    return m

print(tim_max(10, 25, 15)) # Output: 25
```
</details>
