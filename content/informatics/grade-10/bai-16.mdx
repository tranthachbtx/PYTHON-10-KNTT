### Khởi động: Code bằng ngôn ngữ nào dễ nhất?

Check hình dưới này xem, đoạn code nào bạn đọc hiểu được? 👀

```text
01101101 01101001 01101110 01100000  ← Ngôn ngữ máy (mã nhị phân)
01101110 00100000 01110100 01110010
```

Hay là:

```assembly
RESETA  EQU  %0010011              ← Hợp ngữ (Assembly)
CTLREG  EQU  %0010001
INITA   LDA A #RESETA
```

Hoặc đơn giản thế này:


```python
# Nhập từ bàn phím dãy n số và tính tổng
n = int(input("Nhập số tự nhiên n: "))
s = 0
for i in range(n):
    a = int(input("Nhập số thứ " + str(i+1) + ": "))
    s = s + a
print("Tổng các số đã nhập là:", s)
```

## 1. Ngôn ngữ lập trình bậc cao là gì?

### Câu chuyện từ thời đồ đá...
Ngày xưa, lập trình viên phải code bằng mã nhị phân (toàn số 0 và 1) hoặc hợp ngữ (các từ viết tắt tiếng Anh khó hiểu). Viết vài dòng code mà muốn... khóc 😭

May mắn thay, các cao nhân đã phát minh ra **ngôn ngữ lập trình bậc cao** - viết code gần giống nói chuyện, máy tính tự hiểu và dịch ra ngôn ngữ máy giúp mình!

<GlassCard title="Ngôn ngữ lập trình bậc cao 101">
**Định nghĩa nhanh:**
- Các câu lệnh viết **gần với ngôn ngữ tự nhiên** (đọc hiểu dễ hơn nhiều)
- Máy tính cần **chương trình dịch** để hiểu (compiler/interpreter)
- Ví dụ: Java, C/C++, Python, JavaScript...

**Tại sao lại gọi là "bậc cao"?**
Vì nó ở "tầng cao" hơn so với ngôn ngữ máy - xa phần cứng, gần con người hơn!
</GlassCard>

## 2. Môi trường lập trình Python

### Giao diện Python trông như nào?
Khi mở Python lên, bạn sẽ thấy màn hình tương tự thế này:
```text
Python 3.x.x
>>> _
```
Dấu `>>>` này gọi là **dấu nhắc** (prompt) - nơi bạn gõ lệnh!

### Hai chế độ chiến đấu 🎮

Python có 2 mode để bạn lựa chọn:

<GlassCard title="1️⃣ Chế độ gõ lệnh trực tiếp (Interactive Mode)">
**Đặc điểm:**
- Gõ lệnh → Enter → Kết quả ngay lập tức
- Dùng để test nhanh, thử nghiệm
- Giống như chat với Python vậy

**Ví dụ:**
```python
>>> 5 + 3
8
>>> print("Hello World!")
Hello World!
```
</GlassCard>

<GlassCard title="2️⃣ Chế độ soạn thảo (Script Mode)">
**Đặc điểm:**
- Viết nhiều dòng lệnh trong file
- Lưu file → Chạy toàn bộ chương trình
- Dùng cho chương trình thực tế
- Cách mở: `File` → `New File` (hoặc `Ctrl+N`)
</GlassCard>

<Alert type="warning">
**Lưu ý:** Khi viết chương trình, nhớ lưu file với đuôi `.py` nhé! Ví dụ: `bai1.py`, `hello_world.py`...
</Alert>

## 3. Lệnh Python đầu tiên của bạn

### Thử nghiệm nhanh với Interactive Mode


```python
>>> 5
5

>>> 2.6
2.6

>>> "học sinh lớp 10"
'học sinh lớp 10'

>>> 3 + 7
10

>>> 12 * 5
60
```


Thấy chưa? Python tự nhận biết kiểu dữ liệu và tính toán luôn! 🎯

### Lệnh `print()` - Vũ khí đầu tiên

<GlassCard title="Lệnh print() - In dữ liệu ra màn hình">
**Cú pháp:**
```python
print(v1, v2, ..., vn)
```

**Công dụng:**
- In một hoặc nhiều giá trị ra màn hình
- Tự động thêm dấu cách giữa các giá trị
- Có thể tính toán biểu thức luôn

**Ví dụ:**
```python
>>> print(12)
12

>>> print(10, 3.4 + 4.1, "hoà bình")
10 7.5 hoà bình

>>> print("3 + 7 =", 3+7)
3 + 7 = 10
```
</GlassCard>

### Thử thách: Chương trình Python đầu tiên! 🎉

Giờ làm một chương trình hoàn chỉnh nào!


```python
# Chương trình đầu tiên
# Dấu # là chú thích, Python sẽ bỏ qua dòng này
print("Xin chào!")
print("Đây là chương trình Python đầu tiên của mình!")
print("Let's gooooo! 🚀")
```


**Các bước thực hiện:**
1. **Bước 1:** Mở Python (double click vào icon)
2. **Bước 2:** Chọn `File` → `New File`
3. **Bước 3:** Gõ code vào
4. **Bước 4:** Lưu file (`Ctrl+S`) với tên `bai1.py`
5. **Bước 5:** Chạy chương trình (nhấn `F5` hoặc `Run` → `Run Module`)
6. **Bước 6:** Ngắm kết quả và tự hào! 💪

<Alert type="success">
**Thoát chương trình:** Gõ `quit()` hoặc `exit()` rồi Enter, hoặc nhấn nút X ở góc màn hình.
</Alert>
