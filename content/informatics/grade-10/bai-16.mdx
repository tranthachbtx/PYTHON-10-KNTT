<StepKnowledge title="2. Hình thành kiến thức (Knowledge)">
  <RawContent>
    ### 1. Ngôn ngữ lập trình bậc cao
    **Ngôn ngữ lập trình bậc cao** là ngôn ngữ có các câu lệnh được viết gần với ngôn ngữ tự nhiên, giúp việc đọc, hiểu chương trình dễ dàng hơn.
    
    Các lệnh viết bằng ngôn ngữ máy (mã nhị phân) hay hợp ngữ không thuận tiện cho việc viết hoặc hiểu chương trình. Để máy tính có thể hiểu và thực hiện, các chương trình ngôn ngữ bậc cao cần được dịch sang ngôn ngữ máy nhờ **chương trình dịch**.
    
    Hiện nay có nhiều ngôn ngữ lập trình bậc cao, trong đó Java, C/C++, Python là những ngôn ngữ thông dụng nhất.
    
    ### 2. Ngôn ngữ lập trình Python
    Python là ngôn ngữ lập trình bậc cao do **Guido van Rossum** (người Hà Lan) tạo ra và ra mắt lần đầu năm 1991.
    
    **Đặc điểm của Python:**
    - Các câu lệnh có cú pháp đơn giản
    - Môi trường lập trình dễ sử dụng
    - Không phụ thuộc vào hệ điều hành
    - Chạy trên nhiều loại máy tính, điện thoại thông minh, robot giáo dục
    - Có mã nguồn mở
    - Thư viện chương trình phong phú về trí tuệ nhân tạo, phân tích dữ liệu, kỹ thuật robot
    - Được dùng phổ biến trong nghiên cứu và giáo dục

    ### 3. Môi trường lập trình Python
    Phần mềm Python là môi trường lập trình cho phép soạn thảo chương trình bằng ngôn ngữ Python, hỗ trợ gõ lỗi, phân tích cú pháp dòng lệnh và thực hiện các chương trình Python.
    
    Python có **hai chế độ** làm việc:
    
    #### a) Chế độ gõ lệnh trực tiếp
    - Thường được dùng để tính toán và kiểm tra nhanh các lệnh
    - Có dấu nhắc lệnh `>>>`
    
    #### b) Chế độ soạn thảo chương trình
    - Dùng để viết các chương trình có nhiều dòng lệnh
    - Chọn File/New File để mở màn hình soạn thảo
    - Viết mỗi lệnh trên một dòng
    - Lưu chương trình và chọn Run để thực hiện
    
    <Alert type="tip" title="Lưu ý">
    Người ta có thể soạn thảo chương trình Python bằng phần mềm soạn thảo văn bản hoặc phần mềm lập trình Python như Wingware, PyCharm, Thonny, Visual Studio...
    </Alert>

    ### 4. Một số lệnh Python đầu tiên
    #### a) Lệnh print()
    Python tự nhận biết kiểu dữ liệu và thực hiện các phép toán ngay trên dòng lệnh.
    
    **Ví dụ các lệnh đầu tiên:**
    ```python
    5
    5
    2.6
    2.6
    "học sinh lớp 10"
    'học sinh lớp 10'
    ```
    
    #### b) Các phép toán
    Các phép toán thông thường với số bao gồm: cộng (+), trừ (-), nhân (*) và chia (/).
    
    **Ví dụ:**
    ```python
    3 + 7
    10
    12*5
    60
    ```
    
    #### c) Lệnh print() với nhiều giá trị
    ```python
    print(12)
    12
    print(10,3.4 + 4.1, "hoà bình")
    10 7.5 hoà bình
    print("Dãy ba số chẵn:", 2,4,6)
    Dãy ba số chẵn: 2 4 6
    print("3 + 7 =", 3+7)
    3 + 7 = 10
    ```
    
    **Lưu ý:** Nếu lệnh print() nhiều giá trị thì các dữ liệu này sẽ được đưa ra trên một dòng, giữa các dữ liệu sẽ có dấu cách.
    
    Lệnh print() có thể tính toán và đưa ra kết quả của biểu thức.
