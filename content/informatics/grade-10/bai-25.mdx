    ### 1. Xâu con và lệnh tìm vị trí xâu con
    
    #### a) Kiểm tra xâu con với toán tử in
    Toán tử in dùng để kiểm tra một xâu có là xâu con của xâu khác không.
    
    **Cú pháp:**
    ```python
    <xâu_con> in <xâu_mẹ>
    ```
    
    **Ví dụ:**
    ```python
    "abc" in "123abc"      # True
    "010" in "1101"        # False
    ```
    
    Nếu đúng thì trả lại giá trị True, nếu sai trả lại giá trị False.
    
    #### b) Lệnh find() tìm vị trí xâu con
    Lệnh find() tìm vị trí xuất hiện của một xâu trong xâu khác.
    
    **Cú pháp đơn:**
    ```python
    <xâu_mẹ>.find(<xâu_con>)
    ```
    
    Lệnh sẽ tìm vị trí đầu tiên của xâu con trong xâu mẹ và trả về vị trí đó. Nếu không tìm thấy thì trả về -1.
    
    **Ví dụ:**
    ```python
    s = "ab bc cd 123 456 00"
    s.find("b")        # 1 - Vị trí xuất hiện đầu tiên của "b"
    s.find("12")       # 9 - Vị trí tìm thấy đầu tiên của "12"
    s.find("AB")       # -1 - Không tìm thấy xâu "AB"
    ```
    
    **Cú pháp đầy đủ:**
    ```python
    <xâu_mẹ>.find(<xâu_con>, <vị trí bắt đầu>)
    ```
    
    Lệnh sẽ tìm vị trí xâu con bắt đầu từ vị trí start.
    
    **Ví dụ:**
    ```python
    sub = "Đà Nẵng"
    s = "Hà Nội - Đà Nẵng - Hồ Chí Minh"
    s.find(sub)         # 9
    s.find(sub, 10)     # -1 - Bắt đầu tìm từ vị trí 10 trở đi
    ```

    ### 2. Một số lệnh thường dùng với xâu kí tự
    
    #### a) Lệnh split() tách xâu thành danh sách
    Lệnh split() tách một xâu thành các từ và đưa vào một danh sách. Kí tự tách dùng để phân tách các từ mặc định là dấu cách, tuy nhiên có thể thay thế kí tự tách bằng kí tự khác.
    
    **Cú pháp:**
    ```python
    <xâu>.split(<kí tự tách>)
    ```
    
    **Ví dụ:**
    ```python
    s = "Tiên học lễ hậu học văn"
    s.split()  # Tách xâu dùng dấu cách để phân biệt tách
    # ['Tiên', 'học', 'lễ', 'hậu', 'học', 'văn']
    
    st = "0,1,2,3,4,5,6,10"
    st.split(",")  # Tách xâu dùng dấu "," để phân biệt tách
    # ['0', '1', '2', '3', '4', '5', '6', '10']
    ```
    
    #### b) Lệnh join() nối danh sách thành xâu
    Lệnh join() nối danh sách gồm các từ thành một xâu.
    
    **Ví dụ:**
    ```python
    ds = ['Tiên', 'học', 'lễ']
    " ".join(ds)  # "Tiên học lễ"
    
    ds_so = ['0', '1', '2', '3']
    ",".join(ds_so)  # "0,1,2,3"
    ```

    #### Bài tập 4:
    Viết chương trình kiểm tra xâu S có chứa chữ số không. Thông báo "S có chứa chữ số" hoặc "S không chứa chữ số nào".
    
    **Gợi ý:**
    ```python
    co_chu_so = False
    for ch in S:
        if ch.isdigit():
            co_chu_so = True
            break
    
    if co_chu_so:
        print("S có chứa chữ số")
    else:
        print("S không chứa chữ số nào")
    ```
    
    #### Thực hành tại máy:
    Nhập một xâu kí tự S từ bàn phím rồi kiểm tra xem xâu S có chứa xâu con "10" không.
    
    **Cách 1: Duyệt kí tự theo chỉ số**
    ```python
    S = input("Nhập xâu kí tự bất kì: ")
    kq = False
    for i in range(len(S)-1):
        if S[i] == "1" and S[i+1] == "0":
            kq = True
            break
    
    if kq:
        print("Xâu gốc có chứa xâu '10'")
    else:
        print("Xâu gốc không chứa xâu '10'")
    ```
    
    **Cách 2: Sử dụng toán tử in**
    ```python
    S = input("Nhập xâu kí tự bất kì: ")
    if "10" in S:
        print("Xâu gốc có chứa xâu '10'")
    else:
        print("Xâu gốc không chứa xâu '10'")
    ```

    ### Bài tập vận dụng
    
    #### Bài tập 1: Chèn xâu vào giữa
    Cho hai xâu s₁, s₂. Viết đoạn chương trình chèn xâu s₁ vào giữa s₂, tại vị trí len(s₂)//2. In kết quả ra màn hình.
    
    **Gợi ý:**
    ```python
    s1 = input("Nhập xâu s1: ")
    s2 = input("Nhập xâu s2: ")
    
    vi_tri = len(s2) // 2
    ket_qua = s2[:vi_tri] + s1 + s2[vi_tri:]
    print("Kết quả:", ket_qua)
    ```
    
    #### Bài tập 2: Đếm tên trùng lặp
    Viết chương trình nhập số học sinh và họ tên học sinh. Sau đó đếm xem trong danh sách có bao nhiêu bạn tên là "Hương".
    
    **Gợi ý:** Sử dụng toán tử in để kiểm tra một xâu có là xâu con của một xâu khác.
    
    **Chương trình mẫu:**
    ```python
    n = int(input("Nhập số học sinh: "))
    ds_lop = []
    
    for i in range(n):
        hoten = input("Nhập họ tên học sinh thứ " + str(i+1) + ": ")
        ds_lop.append(hoten)
    
    dem_huong = 0
    for ten in ds_lop:
        if "Hương" in ten:
            dem_huong += 1
    
    print("Số bạn tên Hương:", dem_huong)
    ```
    
    #### Bài tập 3: Xử lý dữ liệu CSV
    Viết chương trình xử lý xâu dữ liệu dạng CSV (cách nhau bởi dấu phẩy):
    - Nhập xâu: "Tên, Tuổi, Lớp"
    - Tách thành danh sách và in từng phần tử trên dòng riêng
    
    **Gợi ý:**
    ```python
    du_lieu = input("Nhập dữ liệu CSV: ")
    danh_sach = du_lieu.split(",")
    
    for i, phan_tu in enumerate(danh_sach):
        print(f"Phần tử {i+1}: {phan_tu.strip()}")
    ```
