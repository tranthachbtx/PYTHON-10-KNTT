    ### 1. Cách sử dụng chương trình con
    
    #### Ví dụ 1: In các số nguyên tố nhỏ hơn hoặc bằng n
    
    Chương trình hoàn chỉnh giải bài toán trên có thể được viết như sau:
    
    ```python
    def prime(n):
        C = 0
        k = 1
        while k < n:
            if n % k == 0:
                C = C + 1
            k = k + 1
        if C == 1:
            return True
        else:
            return False
    
    # Chương trình chính
    n = int(input("Nhập số tự nhiên n: "))
    for k in range(1, n + 1):
        if prime(k):  # Sử dụng hàm prime đã định nghĩa ở trên để kiểm tra số k
            print(k, end = " ")
    ```
    
    Hàm prime(k) sẽ trả lại True nếu k là số nguyên tố.

    #### Ví dụ 2: Tính tổng các số dương trong dãy
    
    Cho trước hai dãy số B, C, chương trình chính cần tính tổng các số hạng dương của mỗi dãy này. Chúng ta sẽ thiết lập hàm tongduong(A) để tính tổng các số hạng lớn hơn 0 của một dãy A.
    
    ```python
    def tongduong(A):
        S = 0
        for k in A:
            if k > 0:
                S = S + k
        return S
    
    # Chương trình chính
    A = [0, 2, -1, 5, 10, -3]
    B = [1, -10, -11, 8, 2, 0, -5]
    
    print(tongduong(A))  # 17
    print(tongduong(B))  # 11
    ```

    def prime(n):
        if n < 2:
            return False

                return False
        return True

    ### Bài tập vận dụng
    
    #### Bài tập 1: Hàm tính tổng có điều kiện
    Thiết lập hàm f_sum(A, b) có chức năng tính tổng các số của danh sách A theo quy định sau:
    - Nếu b = 0 thì tính tổng các số của danh sách A
    - Nếu b khác 0 thì chỉ tính tổng các số dương của A
    
    **Chương trình mẫu:**
    ```python
    def f_sum(A, b):
        S = 0
        for x in A:
            if b == 0:
                S = S + x
            else:
                if x > 0:
                    S = S + x
        return S
    
    # Sử dụng hàm
    danh_sach = [1, -2, 3, -4, 5]
    print("Tổng tất cả:", f_sum(danh_sach, 0))
    print("Tổng số dương:", f_sum(danh_sach, 1))
    ```
    
    #### Bài tập 2: Hàm đếm từ
    Thiết lập hàm f_dem(msg, sep) có chức năng đếm số các từ của một xâu msg với kí tự tách từ là sep.
    
    **Ví dụ:**
    - f_dem("Mùa thu lịch sử", "") → Trả lại giá trị 4
    - f_dem("Mùa thu lịch sử", "-") → Trả lại giá trị 1
    
    **Chương trình mẫu:**
    ```python
    def f_dem(msg, sep):
        xlist = msg.split(sep)
        return len(xlist)
    
    # Sử dụng hàm
    print(f_dem("Mùa thu lịch sử", ""))      # 4
    print(f_dem("Mùa-thu-lịch-sử", "-"))    # 4
    print(f_dem("Mùa thu lịch sử", "-"))    # 1
    ```
    
    #### Bài tập 3: Hàm gộp xâu xen kẽ
    Thiết lập hàm merge_str(s1, s2) với s1, s2 là hai xâu cần gộp.
    Hàm này sẽ gộp hai xâu s1, s2 theo cách, lấy lần lượt từng kí tự của s1, s2 đưa vào xâu kết quả. Nếu có một xâu hết kí tự thì đưa phần còn lại của xâu dài hơn vào xâu kết quả.
    
    **Ví dụ:** nếu s1 = "1111", s2 = "0000" thì xâu kết quả là "10101010".
    
    **Chương trình mẫu:**
    ```python
    def merge_str(s1, s2):
        S = ""
        l1 = len(s1)
        l2 = len(s2)
        l = min(l1, l2)
        for i in range(l):
            S = S + s1[i] + s2[i]
        # Thêm phần còn lại của xâu dài hơn
        if l1 > l:
            S = S + s1[l:]
        elif l2 > l:
            S = S + s2[l:]
        return S
    
    # Sử dụng hàm
    print(merge_str("1111", "0000"))  # 10101010
    print(merge_str("ABC", "12345"))  # 1A2B3C45
    ```
