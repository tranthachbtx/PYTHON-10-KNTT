<StepKnowledge title="2. Thực hành tổng hợp (Knowledge & Practice)">
  <RawContent>
    ### Nhiệm vụ 1: Hàm kiểm tra số chính phương
    Số chính phương là số có căn bậc hai là một số nguyên (VD: 4, 9, 16...).
    
    ```python
    import math

    def la_so_chinh_phuong(n):
        can = math.sqrt(n)
        if can == int(can):
            return True
        else:
            return False

    # Chạy thử
    so = int(input("Nhập số cần kiểm tra: "))
    if la_so_chinh_phuong(so):
        print(so, "là số chính phương!")
    else:
        print(so, "không phải số chính phương.")
    ```

    ### Nhiệm vụ 2: Truyền List vào hàm
    Viết hàm `them_diem_cong(ds_diem, diem_thuong)` để cộng thêm điểm cho tất cả học sinh trong danh sách.
    
    ```python
    def them_diem_cong(ds_diem, diem_thuong):
        for i in range(len(ds_diem)):
            ds_diem[i] = ds_diem[i] + diem_thuong
            if ds_diem[i] > 10: ds_diem[i] = 10 # Không quá 10 điểm

    bang_diem = [7.5, 8.0, 9.5, 6.0]
    them_diem_cong(bang_diem, 0.5)
    print("Bảng điểm sau khi cộng:", bang_diem)
    ```
  </RawContent>
  <TeacherNotes>
    **Mục tiêu:** 
    - HS biết cách import thư viện `math`.
    - HS hiểu cơ chế thay đổi List gốc khi truyền vào hàm.
    
    **Tổ chức thực hiện:**
    - GV giải thích tại sao `can == int(can)` là cách kiểm tra số nguyên.
    - HS thực hành gõ code và chạy thử với nhiều bộ dữ liệu (test cases).
  </TeacherNotes>
</StepKnowledge>

<StepPractice title="3. Luyện tập nâng cao (Practice)">
  <RawContent>
    #### 🛠️ Nhiệm vụ 3: "Hàm đa năng"
    Viết hàm `tim_max_min(ds)` nhận vào danh sách số và trả về cùng lúc cả giá trị lớn nhất và nhỏ nhất.
    
    ```python
    def tim_max_min(ds):
        if len(ds) == 0: return None, None
        v_max = ds[0]
        v_min = ds[0]
        for x in ds:
            if x > v_max: v_max = x
            if x < v_min: v_min = x
        return v_max, v_min

    a = [3, 8, 1, 9, 2]
    m_max, m_min = tim_max_min(a)
    print("Lớn nhất:", m_max, "- Nhỏ nhất:", m_min)
    ```
  </RawContent>
  <TeacherNotes>
    **Mục tiêu:** HS biết cách trả về nhiều giá trị từ một hàm (Tuple return).
    **Sản phẩm:** Hàm tìm max/min hoạt động chính xác.
  </TeacherNotes>
</StepPractice>
