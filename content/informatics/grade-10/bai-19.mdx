<StepKnowledge title="2. Hình thành kiến thức (Knowledge)">
  <RawContent>
    ### 1. Biểu thức lôgic (Boolean)
    Mọi điều kiện rẽ nhánh đều dựa trên một kết quả: **Đúng (True)** hoặc **Sai (False)**.
    
    #### Các phép so sánh:
    - `==` (Bằng), `!=` (Khác).
    - `>`, `<`, `>=` (Lớn hơn hoặc bằng), `<=` (Nhỏ hơn hoặc bằng).

    #### Các phép toán logic (Kết hợp):
    - `and`: Cả 2 cùng đúng mới ra True.
    - `or`: Chỉ cần 1 trong 2 đúng là ra True.
    - `not`: Đảo ngược True <-> False.

    ### 2. Câu lệnh rẽ nhánh if
    Python quy định cách viết rất nghiêm ngặt để đảm bảo code sạch và dễ đọc.

    <GlassCard title="Cấu trúc if-else">
    ```python
    if <điều kiện>:
        <khối lệnh làm nếu đúng> # Nhớ thụt dòng!
    else:
        <khối lệnh làm nếu sai>  # Nhớ dấu hai chấm!
    ```
    </GlassCard>

    - **Dấu hai chấm (`:`):** Bắt buộc phải có sau `if` và `else`.
    - **Thụt lề (Indentation):** Mọi lệnh bên trong `if` phải thụt vào cùng một khoảng (thường là 4 dấu cách).

    ### 3. Cấu trúc rẽ nhánh nhiều nhánh (`if-elif-else`)
    Dùng khi có từ 3 lựa chọn trở lên (ví dụ xếp loại học lực).
    Python kiểm tra từ trên xuống dưới, gặp điều kiện nào đúng sẽ làm rồi thoát khỏi khối `if`.

<StepPractice title="3. Luyện tập (Practice)">
  <RawContent>
    #### 🛠️ Nhiệm vụ 1: Kiểm tra chẵn lẻ
    Viết chương trình nhập số nguyên `n`. Nếu `n` chia hết cho 2 thì in "Số chẵn", ngược lại in "Số lẻ".
    
    #### 🛠️ Nhiệm vụ 2: Xếp loại học tập
    Viết chương trình nhập điểm trung bình môn Tin học.
    - Nếu điểm >= 8.0: In "Bạn học rất tốt!".
    - Nếu điểm >= 5.0: In "Bạn đạt yêu cầu.".
    - Ngược lại: In "Bạn cần cố gắng hơn nhé!".

    ```python
    diem = float(input("Nhập điểm Tin học: "))
    if diem >= 8.0:
        print("Bạn học rất tốt!")
    elif diem >= 5.0:
        print("Bạn đạt yêu cầu.")
    else:
        print("Bạn cần cố gắng hơn nhé!")
    ```
  </RawContent>
  <TeacherNotes>
    **Mục tiêu:** HS vận dụng cấu trúc rẽ nhánh thiếu (if), đủ (if-else) và nhiều nhánh (if-elif-else).
    **Sản phẩm:** Hai chương trình thực thi đúng với mọi bộ dữ liệu đầu vào.
  </TeacherNotes>
</StepPractice>
