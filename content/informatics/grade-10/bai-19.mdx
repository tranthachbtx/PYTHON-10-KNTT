## 1. Biểu thức lôgic (Boolean Expression)

Trước khi rẽ nhánh, chương trình cần thực hiện một phép kiểm tra điều kiện. Kết quả của phép kiểm tra này luôn là **Đúng (True)** hoặc **Sai (False)**.

### a) Các phép so sánh
Python sử dụng các ký hiệu sau để so sánh các giá trị:

| Phép toán | Ý nghĩa | Ví dụ | Kết quả |
| :--- | :--- | :--- | :--- |
| `==` | Bằng nhau | `5 == 5` | `True` |
| `!=` | Khác nhau | `5 != 10` | `True` |
| `>` | Lớn hơn | `5 > 10` | `False` |
| `<` | Nhỏ hơn | `5 < 10` | `True` |
| `>=` | Lớn hơn hoặc bằng | `10 >= 10` | `True` |
| `<=` | Nhỏ hơn hoặc bằng | `8 <= 5` | `False` |

### b) Các phép toán lôgic
Chúng ta có thể kết hợp nhiều điều kiện bằng các phép toán:
- **`and` (Và):** Trả về `True` nếu **tất cả** các điều kiện đều đúng.
- **`or` (Hoặc):** Trả về `True` nếu chỉ cần **ít nhất một** điều kiện đúng.
- **`not` (Phủ định):** Đảo ngược giá trị (`True` thành `False` và ngược lại).

*Ví dụ:* `(5 > 3) and (10 < 20)` => `True and True` => `True`.

## 2. Câu lệnh rẽ nhánh IF

Trong Python, dấu hai chấm (`:`) và việc **thụt đầu dòng** là bắt buộc để xác định khối lệnh thuộc về `if`.

### a) Dạng thiếu (Chỉ có IF)
Máy tính chỉ làm việc gì đó khi điều kiện Đúng. Nếu điều kiện Sai, máy bỏ qua và làm lệnh tiếp theo.

**Cú pháp:**
```python
if <điều kiện>:
    <khối lệnh>
```

### b) Dạng đủ (IF ... ELSE)
Máy tính sẽ chọn 1 trong 2 hướng hành động tùy vào kết quả của điều kiện.

**Cú pháp:**
```python
if <điều kiện>:
    <khối lệnh 1 (làm nếu Đúng)>
else:
    <khối lệnh 2 (làm nếu Sai)>
```

---

## 3. Cấu trúc rẽ nhánh lồng nhau và `elif`

Khi bài toán có nhiều hơn 2 hướng giải quyết (ví dụ xếp loại học sinh), chúng ta dùng `elif`.

**Cú pháp tổng quát:**
```python
if <điều kiện 1>:
    <lệnh 1>
elif <điều kiện 2>:
    <lệnh 2>
...
else:
    <lệnh cuối cùng>
```

## 💻 Thực hành: Xử lý các tình huống logic

<GlassCard title="Bài toán 1: Kiểm tra số chẵn số lẻ">
**Yêu cầu:** Nhập một số nguyên `n` và thông báo xem nó là chẵn hay lẻ.

**Mã nguồn:**
```python
n = int(input("Nhập số nguyên n: "))
if n % 2 == 0:
    print(n, "là số chẵn.")
else:
    print(n, "là số lẻ.")
```
</GlassCard>

<GlassCard title="Bài toán 2: Tính tiền điện (Đơn giản)">
**Yêu cầu:** Nhập số điện tiêu thụ `k`. Nếu `k <= 50` thì giá là 1.678đ/số. Nếu `k > 50` thì các số điện từ 51 trở đi giá là 1.734đ/số.

**Mã nguồn:**
```python
k = int(input("Nhập số điện tiêu thụ: "))
if k <= 50:
    tien = k * 1678
else:
    tien = 50 * 1678 + (k - 50) * 1734
print("Tổng tiền điện là:", tien, "đồng")
```
</GlassCard>

## 📚 Tổng kết

<Alert type="success">
- ✅ Kiểu **Boolean** chỉ có 2 giá trị: `True` và `False`.
- ✅ Lệnh `if` điều hướng chương trình dựa trên biểu thức điều kiện.
- ✅ Nhớ kỹ: Sau `if`, `else`, `elif` luôn phải có **dấu hai chấm (:)**.
- ✅ Khối lệnh bên trong phải được **thụt lề** đều nhau.
</Alert>
