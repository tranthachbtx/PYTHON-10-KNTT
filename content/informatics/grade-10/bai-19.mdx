    ### 1. Biểu thức logic
    Trong Python, biểu thức logic là biểu thức chỉ nhận giá trị **True (đúng)** hoặc **False (sai)**. Biểu thức logic đơn giản nhất là các biểu thức so sánh số hoặc xâu kí tự.
    
    **Ví dụ về biểu thức logic:**
    ```python
    a, b, s = 10, 2, "Number"
    
    a > 10
    False
    
    b < 3
    True
    
    s == "number"
    False
    ```
    
    #### a) Các phép so sánh
    Các phép so sánh các giá trị số trong Python:
    
    | Phép toán | Ý nghĩa | Ví dụ |
    |-----------|---------|-------|
    | `<` | Nhỏ hơn | `a < 10` |
    | `>` | Lớn hơn | `a > 5` |
    | `==` | Bằng nhau | `a == 10` |
    | `<=` | Nhỏ hơn hoặc bằng | `a <= 10` |
    | `>=` | Lớn hơn hoặc bằng | `a >= 5` |
    | `!=` | Khác nhau | `a != 5` |
    
    **Lưu ý:** Với xâu kí tự cũng có đầy đủ các phép so sánh (sẽ học sau).
    
    #### b) Các phép toán logic
    Các phép toán trên kiểu dữ liệu logic bao gồm:
    
    **Phép and (và):**
    | X | Y | X and Y |
    |---|---|---------|
    | True | True | True |
    | True | False | False |
    | False | True | False |
    | False | False | False |
    
    **Phép or (hoặc):**
    | X | Y | X or Y |
    |---|---|---------|
    | True | True | True |
    | True | False | True |
    | False | True | True |
    | False | False | False |
    
    **Phép not (phủ định):**
    | X | not X |
    |---|-------|
    | True | False |
    | False | True |
    
    **Ví dụ phức hợp:**
    ```python
    x, y, z = 10, 5, 9
    b = x < 11 and z > 5      # True and True = True
    c = x > 15 or y < 9       # False or True = True
    a = not b                 # not True = False
    ```
    
    **Kết nối tri thức:**
    - Biểu thức logic là biểu thức chỉ nhận giá trị True hoặc False.
    - Giá trị các biểu thức logic thuộc kiểu bool.
    - Các phép toán trên kiểu dữ liệu logic là and (và), or (hoặc) và not (phủ định).

    ### 2. Lệnh if
    Để xử lí các tình huống rẽ nhánh, giống như các ngôn ngữ lập trình khác, Python cũng có các câu lệnh để mô tả cấu trúc rẽ nhánh.
    
    #### a) Câu lệnh rẽ nhánh dạng thiếu
    **Cú pháp:**
    ```python
    if `<điều kiện>`:
        `<khối lệnh>`
    ```
    
    **Quy tắc quan trọng:**
    - Sau điều kiện cần có dấu hai chấm ":"
    - Nhóm, khối lệnh tiếp theo cần viết lùi vào và thẳng hàng, mặc định là 1 tab hay 4 dấu cách
    
    **Ví dụ:**
    ```python
    if n > 0:
        print("n là số lớn hơn 0")
    ```
    
    #### b) Câu lệnh rẽ nhánh dạng đủ
    **Cú pháp:**
    ```python
    if <điều kiện>:
        <khối lệnh 1>
    else:
        <khối lệnh 2>
    ```
    
    **Ví dụ:**
    ```python
    if n > 0:
        print("n là số dương")
    else:
        print("n không phải là số dương")
    ```
    
    #### c) Câu lệnh rẽ nhánh dạng đủ nhiều nhánh
    **Cú pháp:**
    ```python
    if <điều kiện 1>:
        <khối lệnh 1>
    elif <điều kiện 2>:
        <khối lệnh 2>
    else:
        <khối lệnh 3>
    ```

    ### Bài tập vận dụng
    
    #### Bài tập 1: Kiểm tra năm nhuận
    Năm n là năm nhuận nếu giá trị n thoả mãn điều kiện: n chia hết cho 400 hoặc n chia hết cho 4 đồng thời không chia hết cho 100.
    
    Viết chương trình nhập số năm n và cho biết năm n có phải là nhuận hay không.
    
    **Gợi ý:**
    ```python
    if (n % 400 == 0) or (n % 4 == 0 and n % 100 != 0):
        print(n, "là năm nhuận")
    else:
        print(n, "không phải là năm nhuận")
    ```
    
    #### Bài tập 2: Giải phương trình bậc nhất
    Viết chương trình nhập vào các hệ số a, b của phương trình ax + b = 0 (a ≠ 0) và tìm nghiệm của phương trình.
    
    **Gợi ý:**
    - Nghiệm x = -b/a
    - Cần kiểm tra a != 0 trước khi tính
    
    #### Bài tập 3: Tính tiền điện
    Viết chương trình tính tiền điện theo quy định:

    - Nếu số điện > 100 kWh: phần ≤ 100 kWh tính 1.500 VNĐ/kWh, phần vượt tính 2.000 VNĐ/kWh
