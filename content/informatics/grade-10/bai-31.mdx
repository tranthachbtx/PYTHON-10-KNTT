<StepKnowledge title="2. Hình thành kiến thức & Thực hành (Knowledge & Practice)">
  <RawContent>
    ### 1. Module là gì?
    **Module** đơn giản là một tệp Python chứa các định nghĩa hàm, biến... có cùng một chủ đề (ví dụ: thư viện toán học, thư viện xử lý văn bản).

    ### 🛠️ Nhiệm vụ 1: Thiết lập "Hòm đồ nghề" (Module)
    Em hãy tạo một tệp mới đặt tên là `my_tools.py` và gõ các hàm sau vào:
    ```python
    # Tệp my_tools.py
    def la_so_chan(n):
        return n % 2 == 0

    def tinh_tong_ds(ds):
        tong = 0
        for x in ds:
            tong += x
        return tong
    ```

    ### 🛠️ Nhiệm vụ 2: Sử dụng thư viện trong dự án
    Tạo tệp thứ hai (ví dụ `main.py`) nằm cùng thư mục với tệp trên. Sử dụng lệnh `import` để mang các hàm sang sử dụng.
    ```python
    # Tệp main.py
    import my_tools

    a = 10
    if my_tools.la_so_chan(a):
        print(a, "là số chẵn.")

    diem = [8, 9, 10]
    print("Tổng điểm là:", my_tools.tinh_tong_ds(diem))
    ```

    <Alert type="info" title="Mẹo dùng lệnh import">
    - `import my_tools`: Phải dùng `my_tools.ten_ham()` để gọi.
    - `from my_tools import *`: Có thể gọi `ten_ham()` trực tiếp.
    </Alert>
