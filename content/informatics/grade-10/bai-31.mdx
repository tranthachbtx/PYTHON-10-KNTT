## 1. Khái niệm Module (Thư viện)

Hầu hết các chương trình lớn thường được chia thành nhiều tệp mã nguồn nhỏ. Mỗi tệp chứa các hàm có chức năng liên quan (ví dụ: tệp xử lý toán học, tệp xử lý giao diện).
**Lợi ích:**
- Dễ quản lý mã nguồn.
- Có thể mang thư viện này sang dự án khác để dùng lại mà không cần viết lại mã.

---

## 2. Các bước thiết lập thư viện riêng

### Bước 1: Tạo tệp thư viện (Module file)
Em hãy tạo một chương trình mới, viết các hàm muốn dùng chung và lưu lại với tên ví dụ `tienich.py`.

```python
# Tệp: tienich.py
def la_so_nguyen_to(n):
    if n < 2: return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0: return False
    return True

def chu_vi_hinh_tron(r):
    return 2 * 3.14 * r
```

### Bước 2: Sử dụng thư viện trong chương trình khác
Để sử dụng, ta dùng từ khóa `import` ở đầu file chương trình chính.

```python
# Tệp: main.py
import tienich

n = int(input("Nhập số: "))
if tienich.la_so_nguyen_to(n):
    print(n, "là số nguyên tố.")

print("Chu vi đường tròn bán kính 5 là:", tienich.chu_vi_hinh_tron(5))
```

## 3. Hệ thống hóa kiến thức Python lớp 10 🚀

Hãy cùng nhìn lại những khối kiến thức khổng lồ chúng ta đã chinh phục:

1.  **Cơ bản:** Biến, kiểu dữ liệu (`int`, `float`, `str`, `bool`), vào/ra dữ liệu (`print`, `input`).
2.  **Cấu trúc điều khiển:** Rẽ nhánh (`if-elif-else`), Vòng lặp (`for`, `while`).
3.  **Dữ liệu tập hợp:** Danh sách (`List`) và Xâu kí tự (`String`) với các kỹ thuật cắt (`Slice`), tách (`split`), nối (`join`).
4.  **Kỹ thuật nâng cao:** Định nghĩa hàm (`def`), phạm vi biến (`Global/Local`), kiểm thử và gỡ lỗi.

## 💻 Thực hành: Xây dựng thư viện hình học

<GlassCard title="Nhiệm vụ: Module MyGeometry">
**Yêu cầu:** Thiết lập thư viện `MyGeometry.py` chứa các hàm tính diện tích hình vuông, hình chữ nhật, hình tròn.

**Mã nguồn thư viện (MyGeometry.py):**
```python
def hinh_vuong(a):
    return a * a

def hinh_chu_nhat(a, b):
    return a * b

def hinh_tron(r):
    import math
    return math.pi * r * r
```

**Mã nguồn chương trình chính:**
```python
import MyGeometry

print("Diện tích hình tròn r=5 là:", MyGeometry.hinh_tron(5))
print("Diện tích hình vuông cạnh 4 là:", MyGeometry.hinh_vuong(4))
```
</GlassCard>
