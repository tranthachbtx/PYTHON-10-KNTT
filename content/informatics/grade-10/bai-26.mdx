Khi viết các chương trình lớn và phức tạp, việc viết hàng nghìn dòng mã liên tục sẽ khiến chương trình khó đọc và khó sửa lỗi. Giải pháp tuyệt vời trong lập trình là chia nhỏ chương trình thành các phần độc lập gọi là **Hàm**. 🧱📦

## 1. Khái niệm Hàm (Function)

### a) Tại sao cần dùng Hàm?
Hãy tưởng tượng em cần tính diện tích hình tròn ở nhiều nơi khác nhau trong chương trình. Thay vì viết lại công thức đó nhiều lần, em chỉ cần định nghĩa nó một lần và gọi nó ra bất cứ khi nào cần.
**Lợi ích:**
- Tiết kiệm thời gian, công sức.
- Chương trình ngắn gọn, dễ hiểu.
- Dễ dàng sửa lỗi (chỉ cần sửa một lần trong hàm).

### b) Phân loại Hàm
1.  **Hàm có sẵn:** Do Python cung cấp như `print()`, `len()`, `int()`, `input()`, `type()`...
2.  **Hàm tự định nghĩa:** Do người lập trình tự viết để phục vụ mục đích riêng.

---

## 2. Cách thiết lập Hàm trong Python

Để tạo một hàm, chúng ta sử dụng từ khóa `def` (viết tắt của *define*).

**Cú pháp tổng quát:**
```python
def <tên hàm>(<các tham số>):
    <khối lệnh trong hàm>
    return <giá trị trả về> (không bắt buộc)
```

**Quy tắc:**
- Tên hàm tuân theo quy tắc đặt tên tên biến.
- Sau tên hàm là cặp ngoặc đơn `()` (có thể chứa tham số hoặc không).
- Kết thúc dòng định nghĩa là dấu hai chấm `:`.
- Các lệnh trong hàm phải được **thụt đầu dòng**.

---

## 3. Các loại hàm cơ bản

### a) Hàm không có giá trị trả về
Lệnh `return` được bỏ qua hoặc chỉ dùng để kết thúc hàm mà không mang theo giá trị.

```python
def loi_chao(ten):
    print("Chào bạn", ten)
    print("Chúc bạn một ngày học tập vui vẻ!")

# Gọi hàm
loi_chao("Nam")
```

### b) Hàm có giá trị trả về (Dùng `return`)
Hàm thực hiện tính toán và gửi kết quả lại cho nơi gọi nó.

```python
def tinh_tong(a, b):
    tong = a + b
    return tong

# Sử dụng kết quả của hàm
kq = tinh_tong(10, 20)
print("Tổng là:", kq)
```

## 💻 Thực hành: Xây dựng các hàm chức năng

<GlassCard title="Nhiệm vụ 1: Hàm kiểm tra số chẵn">
**Yêu cầu:** Viết hàm `la_so_chan(n)` trả về `True` nếu `n` là chẵn, ngược lại trả về `False`.

**Mã nguồn:**
```python
def la_so_chan(n):
    if n % 2 == 0:
        return True
    else:
        return False

# Kiểm tra thử
so = int(input("Nhập số: "))
if la_so_chan(so):
    print(so, "là số chẵn")
else:
    print(so, "là số lẻ")
```
</GlassCard>

<GlassCard title="Nhiệm vụ 2: Hàm tính thuế thu nhập">
**Yêu cầu:** Viết hàm tính số thuế phải đóng dựa trên thu nhập. Nếu thu nhập dưới 11 triệu thì thuế là 0. Nếu trên 11 triệu thì thuế là 10% phần vượt quá.

**Mã nguồn:**
```python
def tinh_thue(thu_nhap):
    if thu_nhap <= 11:
        return 0
    else:
        return (thu_nhap - 11) * 0.1

luong = float(input("Nhập lương (triệu đồng): "))
print("Thuế phải nộp là:", tinh_thue(luong), "triệu")
```
</GlassCard>
