## 1. Toán tử IN - Kiểm tra phần tử

### Cú pháp cơ bản

<GlassCard title="Toán tử IN">
**Cú pháp:**
```python
giá_trị in danh_sách
```

**Kết quả:**
- `True` nếu có trong danh sách.
- `False` nếu không có.

**Dùng để:**
- Kiểm tra sự tồn tại của phần tử.
- Làm điều kiện trong câu lệnh `if`.
</GlassCard>


```python
>>> A = [1, 2, 3, 4, 5]

# Kiểm tra số 2 có trong A không
>>> 2 in A
True

# Kiểm tra số 10
>>> 10 in A
False

# Dùng trong if
if 3 in A:
    print("Có số 3!")
# Output: Có số 3!

# Phủ định với not
>>> 10 not in A
True
```


### Ví dụ thực tế


```python
# Kiểm tra xem có điểm liệt không
diem = [8, 7, 9, 3, 6]

if 3 in diem or 4 in diem:
    print("Cảnh báo: Có điểm liệt!")
else:
    print("Không có điểm liệt")

# Output: Cảnh báo: Có điểm liệt!
```



```python
# Kiểm tra tên trong danh sách
ds_lop = ["An", "Bình", "Cường", "Dũng"]
ten_can_tim = input("Nhập tên: ")

if ten_can_tim in ds_lop:
    print(ten_can_tim, "có trong lớp")
else:
    print(ten_can_tim, "không có trong lớp")
```

## 2. Duyệt List với toán tử IN

### Duyệt trực tiếp phần tử

Bài trước đã học 2 cách duyệt. Giờ hãy hiểu rõ hơn về cách 2!


```python
>>> A = [10, 11, 12, 13, 14, 15]

# Cách 1: Duyệt theo chỉ số
for i in range(len(A)):
    print(A[i], end=" ")
# Output: 10 11 12 13 14 15

# Cách 2: Duyệt trực tiếp (dùng IN)
for k in A:
    print(k, end=" ")
# Output: 10 11 12 13 14 15
```


<GlassCard title="for ... in ... - Giải thích">
**Cú pháp:**
```python
for phần_tử in danh_sách:
    # phần_tử lần lượt nhận giá trị từ danh sách
```

**Cách hoạt động:**
```python
A = [10, 20, 30]
for x in A:      # x = 10, sau đó 20, rồi 30
    print(x)
```

**So sánh:**
- `for i in range(len(A))`: `i` là chỉ số (0, 1, 2, ...)
- `for x in A`: `x` là giá trị (10, 20, 30, ...)
</GlassCard>

<Alert type="info">
**Từ khóa IN có 2 nghĩa:**
1. **Toán tử kiểm tra:** `if 5 in A:`
2. **Duyệt phần tử:** `for x in A:`

Ngữ cảnh khác nhau, ý nghĩa khác nhau! 🤓
</Alert>

## 3. Các phương thức làm việc với List

### Phương thức clear() - Xóa toàn bộ


```python
>>> A = [1, 2, 3, 4, 5]

# Xóa hết phần tử
>>> A.clear()
>>> A
[]

# List trở thành rỗng
>>> len(A)
0
```


<GlassCard title="So sánh: clear() vs del ⚖️">
Để dọn dẹp danh sách, Python cung cấp hai công cụ với mục tiêu khác nhau. Hãy rà soát kỹ để tránh lỗi Logic!

**1. Phương thức clear()**
- **Mục tiêu:** Xóa "nội dung" bên trong.
- **Kết quả:** Biến vẫn tồn tại, nhưng là một danh sách rỗng `[]`.

**2. Lệnh del**
- **Mục tiêu:** Xóa "đối tượng" và "biến" khỏi bộ nhớ.
- **Kết quả:** Truy cập lại biến sau khi `del` sẽ gây lỗi `NameError`.


```python
A = [1, 2, 3]

# Cách 1: clear() - xóa nội dung, giữ biến
A.clear()
print(A)        # Output: [] (Danh sách rỗng)

# Cách 2: del - giải phóng hoàn toàn
A = [1, 2, 3]
del A
# print(A)      # ❌ Lỗi: NameError: name 'A' is not defined
```

</GlassCard>


### Phương thức remove() - Xóa theo giá trị


```python
>>> A = [1, 2, 3, 4, 5]

# Xóa phần tử có giá trị 1
>>> A.remove(1)
>>> A
[2, 3, 4, 5]

# Xóa tiếp
>>> A.remove(3)
>>> A
[2, 4, 5]
```


<Alert type="warning">
**Lưu ý quan trọng về remove():**

1. **Chỉ xóa phần tử ĐẦU TIÊN tìm thấy:**
```python
>>> A = [1, 2, 3, 2, 4]
>>> A.remove(2)       # Xóa số 2 đầu tiên
>>> A
[1, 3, 2, 4]          # Số 2 thứ 2 vẫn còn!
```

2. **Lỗi nếu không tìm thấy:**
```python
>>> A = [1, 2, 3]
# A.remove(10)      # ValueError: list.remove(x): x not in list
```

3. **Nên kiểm tra trước khi xóa:**

```python
if 10 in A:
    A.remove(10)
```

</Alert>


### Phương thức insert() - Chèn phần tử


```python
>>> A = [1, 2, 6, 10]

# Chèn số 5 vào vị trí chỉ số 2
>>> A.insert(2, 5)
>>> A
[1, 2, 5, 6, 10]
# ↑ Chèn vào đây, đẩy các phần tử sau sang phải

# Chèn vào đầu (chỉ số 0)
>>> A.insert(0, 0)
>>> A
[0, 1, 2, 5, 6, 10]

# Chèn vào cuối
>>> A.insert(len(A), 99)
>>> A
[0, 1, 2, 5, 6, 10, 99]
```


<GlassCard title="insert(index, value) - Chi tiết">
**Cú pháp:**
```python
list.insert(vị_trí, giá_trị)
```

**Hoạt động:**
- Chèn `giá_trị` vào vị trí `vị_trí`.
- Các phần tử từ vị trí đó trở đi dịch sang phải.

**Trường hợp đặc biệt:**
```python
A = [1, 2, 3]
# index < 0 → Chèn vào đầu
A.insert(-100, 0)    # [0, 1, 2, 3]

# index >= len(A) → Chèn vào cuối
A.insert(1000, 99)   # [0, 1, 2, 3, 99]
```
</GlassCard>


```python
# Ví dụ: Tạo list từ rỗng
>>> A = []

# Chèn vào đầu nhiều lần
>>> A.insert(0, 1)
>>> A.insert(0, 2)
>>> A.insert(0, 3)
>>> A
[3, 2, 1]
# Kết quả: List ngược thứ tự nhập!
```

## 4. Tổng hợp các phương thức

<GlassCard title="Bảng tổng hợp phương thức List 📋">
| Phương thức | Chức năng | Ví dụ |
|-------------|-----------|-------|
| `A.append(x)` | Thêm x vào **cuối** | `A.append(5)` |
| `A.insert(k, x)` | Chèn x vào vị trí k | `A.insert(0, 10)` |
| `A.remove(x)` | Xóa x **đầu tiên** | `A.remove(5)` |
| `A.clear()` | Xóa **toàn bộ** | `A.clear()` |
| `len(A)` | Độ dài danh sách | `len(A)` → số phần tử |
| `x in A` | Kiểm tra x có trong A | `5 in A` → True/False |
</GlassCard>

## Thực hành

### Nhiệm vụ 1: Nhập danh sách ngược


```python
# Nhập n tên học sinh, in theo thứ tự ngược lại
n = int(input("Nhập số học sinh: "))
dsLop = []

for i in range(n):
    name = input("Nhập họ tên thứ " + str(i+1) + ": ")
    dsLop.insert(0, name)    # Chèn vào đầu → ngược thứ tự nhập

print("\nDanh sách (ngược):")
for name in dsLop:
    print(name)
```


### Nhiệm vụ 2: Xóa số âm


```python
# Xóa tất cả số âm khỏi danh sách
A = [0, 1, -3, -10, 5, 9, -20, 55]

i = 0
while i < len(A):
    if A[i] < 0:
        A.remove(A[i])    # Xóa số âm
        # Không tăng i vì phần tử sau dịch lên
    else:
        i = i + 1         # Chỉ tăng i khi không xóa

print(A)
# Output: [0, 1, 5, 9, 55]
```


<Alert type="warning">
**Chú ý khi xóa trong vòng lặp:** 

Không nên dùng vòng lặp `for` với `range(len(A))` vì độ dài danh sách sẽ thay đổi liên tục khi có phần tử bị xóa. Cách sử dụng vòng lặp `while` như trên là giải pháp an toàn và chính xác nhất!
</Alert>

## Luyện tập

**Bài 1: Các phép toán với list**
Cho dãy `[1, 2, 2, 3, 4, 5, 5]`. Thực hiện:
a) Chèn số 1 vào ngay sau giá trị 1 đầu tiên.
b) Chèn số 3 và 4 để có 2 cặp [3, 4] liên tiếp.

<details>
<summary>💡 Xem đáp án câu a</summary>

```python
A = [1, 2, 2, 3, 4, 5, 5]
# Tìm vị trí số 1 đầu tiên
vi_tri = A.index(1)
# Chèn vào sau nó (vị trí + 1)
A.insert(vi_tri + 1, 1)
print(A)    # [1, 1, 2, 2, 3, 4, 5, 5]
```
</details>

<details>
<summary>💡 Xem đáp án câu b</summary>

```python
A = [1, 2, 2, 3, 4, 5, 5]

for i in range(len(A) - 1):
    if A[i] == 3 and A[i+1] == 4:
        A.insert(i + 2, 3)
        A.insert(i + 3, 4)
        break

print(A)    # [1, 2, 2, 3, 4, 3, 4, 5, 5]
```
</details>

## Vận dụng

**Thử thách: Dãy Fibonacci**


```python
# Tạo n số hạng đầu của Fibonacci
n = int(input("Nhập n: "))

if n == 0:
    F = []
elif n == 1:
    F = [0]
else:
    F = [0, 1]
    for i in range(2, n):
        next_fib = F[i-1] + F[i-2]
        F.append(next_fib)

print("Dãy Fibonacci:", F)
# Test n=8: [0, 1, 1, 2, 3, 5, 8, 13]
```


<Alert type="success">
**Giải thích Fibonacci:**
Mỗi số (từ số thứ 3 trở đi) bằng tổng của hai số ngay trước nó!
</Alert>
