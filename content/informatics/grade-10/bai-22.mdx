    ### 1. Kiểu dữ liệu danh sách (List)
    List là kiểu dữ liệu danh sách (dãy, mảng) trong Python. Tạo list bằng lệnh gán với các phần tử trong cặp dấu ngoặc [].
    
    #### a) Khởi tạo danh sách
    **Cú pháp:**
    ```python
    <tên_danh_sách> = [<giá trị 1>, <giá trị 2>, ..., <giá trị n>]
    ```
    
    **Đặc điểm:**
    - Các phần tử của danh sách có thể có các kiểu dữ liệu khác nhau
    - Các giá trị cách nhau bởi dấu phẩy
    - Có thể tạo danh sách rỗng
    
    **Ví dụ:**
    ```python
    A = [1, 2, 3, 4, 5]
    B = [1.5, 2, "Python", "List", 0]
    a = []  # Danh sách rỗng
    ```
    
    #### b) Truy cập phần tử
    Truy cập hoặc thay đổi giá trị của từng phần tử thông qua chỉ số:
    ```python
    <tên_danh_sách>[<chỉ số>]
    ```
    
    **Quy tắc quan trọng:**
    - Chỉ số của danh sách bắt đầu từ 0 đến len() - 1
    - len() là lệnh tính độ dài danh sách
    
    **Ví dụ:**
    ```python
    A = [1, 2, 3, 4, 5]
    A[0]    # 1
    B = [1.5, 2, "Python", "List", 0]
    B[2]    # 'Python'
    ```

    ### 2. Thay đổi và xóa phần tử
    
    #### a) Thay đổi giá trị phần tử
    Sử dụng lệnh gán để thay đổi giá trị từng phần tử:
    ```python
    A = [1, 2, 3, 4, 5]
    A[1] = "One"
    print(A)    # [1, 'One', 3, 4, 5]
    ```
    
    #### b) Xóa phần tử
    Sử dụng lệnh del để xóa một phần tử của danh sách:
    ```python
    A = [1, 'One', 3, 4, 5]
    del A[4]
    print(A)    # [1, 'One', 3, 4]
    ```
    
    #### c) Các phép toán với danh sách
    - **len(A)**: Tính độ dài của danh sách
    - **Phép ghép (+)**: Ghép hai danh sách
    
    **Ví dụ:**
    ```python
    a = []  # Danh sách rỗng có độ dài bằng 0
    len(a)  # 0
    
    [1, 2] + [3, 4, 5, 6]  # [1, 2, 3, 4, 5, 6]
    ```

    ### Bài tập thực hành
    
    #### Bài tập 1:
    Cho danh sách A = [1, 0, "One", 9, 15, "Two", True, False]. Hãy cho biết giá trị các phần tử:

    #### Bài tập 2:
    Giả sử A là một danh sách các số, mỗi lệnh sau thực hiện công việc gì?
    a) A = A + [10] b) del A[0] c) A = [100] + A d) A = A[1]*25
    
    #### Bài tập 3:
    Cho dãy các số nguyên A, viết chương trình in ra các số chẵn của A.
    
    **Gợi ý:**
    ```python
    for i in range(len(A)):
        if A[i] % 2 == 0:
            print(A[i], end = " ")
    ```
    
    #### Bài tập 4:
    Viết lệnh xóa phần tử cuối cùng của danh sách A bằng lệnh del.
    
    #### Thực hành tại máy:
    Nhập số n từ bàn phím, sau đó nhập danh sách n tên các bạn lớp em và in ra danh sách các tên đó, mỗi tên trên một dòng.
    
    **Chương trình mẫu:**
    ```python
    dsLop = []
    n = int(input("Nhập số học sinh trong lớp: "))
    for i in range(n):
        name = input("Nhập họ tên học sinh thứ " + str(i+1)+": ")
        dsLop.append(name)
    print("Danh sách học sinh đã nhập:")
    for i in range(len(dsLop)):
        print(dsLop[i])
    ```

    ### Bài tập vận dụng
    
    #### Bài tập 1: Tính tổng và trung bình dãy số
    Nhập một dãy số từ bàn phím. Tính tổng, trung bình của dãy và in dãy số trên một hàng ngang.
    
    **Chương trình mẫu:**
    ```python
    A = []
    T = 0
    n = int(input("Nhập số tự nhiên n: "))
    for i in range(n):
        num = int(input("Nhập số thứ " + str(i+1)+": "))
        A.append(num)
        T = T + num
    
    print("Dãy số đã nhập:")
    for i in range(n):
        print(A[i], end = " ")
    print()
    print("Tổng:", T)
    print("Trung bình:", T/n)
    ```
    
    #### Bài tập 2: Tìm phần tử lớn nhất
    Cho dãy số A. Viết chương trình tìm giá trị và chỉ số của phần tử lớn nhất của A. Tương tự với bài toán tìm phần tử nhỏ nhất.
    
    **Gợi ý:**
    ```python
    max_val = A[0]
    max_index = 0
    for i in range(1, len(A)):
        if A[i] > max_val:
            max_val = A[i]
            max_index = i
    print("Phần tử lớn nhất:", max_val, "tại chỉ số", max_index)
    ```
    
    #### Bài tập 3: Sắp xếp danh sách
    Viết chương trình nhập danh sách các số và sắp xếp theo thứ tự tăng dần.
    
    **Gợi ý:** Có thể dùng phương thức sort() của danh sách: A.sort()
