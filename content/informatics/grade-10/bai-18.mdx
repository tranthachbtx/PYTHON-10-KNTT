## 1. Các lệnh vào ra đơn giản

### a) Lệnh xuất dữ liệu (`print`)
Lệnh `print()` giúp đưa thông tin (hằng, biến, biểu thức) ra màn hình.
- **Cú pháp:** `print(v1, v2, ..., vn)`
- **Đặc điểm:** Các giá trị `v1, v2...` có thể thuộc nhiều kiểu dữ liệu khác nhau và khi in ra sẽ cách nhau bởi một dấu cách mặc định.

*Ví dụ:*
```python
x = 5
print("Giá trị của x là:", x, "và x * 2 =", x * 2)
# Kết quả: Giá trị của x là: 5 và x * 2 = 10
```

### b) Lệnh nhập dữ liệu (`input`)
Lệnh `input()` dùng để nhận dữ liệu nhập từ bàn phím.
- **Cú pháp:** `<biến> = input(<dòng thông báo>)`
- **Hoạt động:** Khi gặp lệnh này, chương trình sẽ dừng lại và hiển thị `<dòng thông báo>`. Người dùng nhập dữ liệu và nhấn **Enter** để gán giá trị đó vào `<biến>`.

<Alert type="warning">
**Lưu ý cực kỳ quan trọng:** Giá trị trả về từ lệnh `input()` luôn là kiểu **xâu kí tự (str)**. Ngay cả khi em nhập vào con số `10`, Python vẫn coi đó là xâu `"10"`.
</Alert>

## 2. Các kiểu dữ liệu cơ bản trong Python

Trong bài toán thực tế, ta cần phân biệt các loại dữ liệu để tính toán chính xác. Python có 4 kiểu cơ bản thường gặp:

1.  **Số nguyên (`int`):** Lưu các số không có phần thập phân (ví dụ: `100`, `-5`).
2.  **Số thực (`float`):** Lưu các số có phần thập phân (ví dụ: `3.14`, `2.0`).
3.  **Xâu kí tự (`str`):** Lưu các văn bản đặt trong dấu nháy (ví dụ: `"Chào bạn"`).
4.  **Kiểu lôgic (`bool`):** Chỉ nhận hai giá trị là `True` (Đúng) hoặc `False` (Sai).

<Alert type="info">
**Lệnh `type()`:** Dùng để kiểm tra kiểu dữ liệu của một đối tượng.
- `type(10)` cho kết quả `<class 'int'>`.
- `type("10")` cho kết quả `<class 'str'>`.
</Alert>

## 3. Các hàm chuyển đổi kiểu dữ liệu

Để thực hiện các phép toán số học trên dữ liệu nhập từ `input()`, ta cần chuyển xâu sang số.

| Hàm | Công dụng | Ví dụ |
| :--- | :--- | :--- |
| `int(x)` | Chuyển `x` sang số nguyên | `int("123")` -> `123` |
| `float(x)` | Chuyển `x` sang số thực | `float("3.14")` -> `3.14` |
| `str(x)` | Chuyển `x` sang xâu kí tự | `str(10)` -> `"10"` |

<Alert type="error">
**Lỗi thường gặp:** Lệnh `int("12.5")` hoặc `int("abc")` sẽ báo lỗi `ValueError` vì Python không thể chuyển xâu chứa dấu phẩy thập phân hoặc chữ cái sang số nguyên trực tiếp.
</Alert>

## 4. Nhập dữ liệu kiểu số

Kết hợp giữa `input()` và hàm chuyển đổi để nhập số từ bàn phím:

```python
# Nhập số nguyên
a = int(input("Nhập số nguyên a: "))

# Nhập số thực
r = float(input("Nhập bán kính r: "))
```

## 💻 Thực hành: Tính tổng và trung bình

<GlassCard title="Bài tập: Nhập điểm 3 môn rèn luyện">
**Yêu cầu:** Nhập vào tên học sinh và điểm môn Toán, Ngữ văn, Tin học. Tính tổng điểm và điểm trung bình.

**Chương trình:**
```python
ten = input("Nhập tên học sinh: ")
toan = float(input("Nhập điểm Toán: "))
van = float(input("Nhập điểm Văn: "))
tin = float(input("Nhập điểm Tin: "))

tong = toan + van + tin
trung_binh = tong / 3

print("Học sinh:", ten)
print("Tổng điểm:", tong)
print("Điểm trung bình:", trung_binh)
```
</GlassCard>
