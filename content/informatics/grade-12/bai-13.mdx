<StepKnowledge title="2. Hình thành kiến thức (Knowledge)">
  <RawContent>
    ### 1. Khái niệm mẫu định dạng CSS

    #### a) CSS là gì?
    **CSS (Cascading Style Sheets - Bảng kiểu xếp tầng)** là một ngôn ngữ đặc biệt được thiết kế để thiết lập các mẫu định dạng trình bày (màu sắc, phông chữ, khoảng cách, kích thước, bố cục) cho các tài liệu viết bằng HTML.

    > [!IMPORTANT]
    > **CSS hoàn toàn độc lập với chuẩn HTML!**  
    > - **HTML** đóng vai trò là "bộ khung xương" và "vật liệu xây dựng", xác định ý nghĩa ngữ nghĩa và cấu trúc nội dung trang web.  
    > - **CSS** đóng vai trò là "lớp sơn", "nội thất" và "trang trí", quyết định cách nội dung đó xuất hiện đẹp mắt trước mắt người dùng.

    #### b) Nguyên lý "Định nghĩa một lần - Dùng nhiều nơi"
    Thay vì phải lặp lại việc định dạng trên từng phần tử, CSS cho phép định nghĩa một quy tắc chung. Ví dụ, chỉ một dòng lệnh CSS sau đây:
    ```css
    p {
      text-indent: 15px;
      line-height: 1.6;
    }
    ```
    Sẽ tự động áp dụng quy tắc thụt đầu dòng 15px và giãn dòng 1.6 cho **tất cả các đoạn văn `<p>`** có mặt trên trang web!

    ---

    ### 2. Cấu trúc tổng quát của mẫu định dạng CSS

    Một quy tắc CSS hoàn chỉnh gồm hai thành phần cơ bản:
    1. **Bộ chọn (Selector):** Chỉ định phần tử HTML nào sẽ được áp dụng định dạng.
    2. **Khối khai báo (Declaration block):** Nằm bên trong cặp ngoặc nhọn `{...}`, chứa một hoặc nhiều khai báo định dạng. Mỗi khai báo gồm **Thuộc tính (Property)** và **Giá trị (Value)**, ngăn cách bởi dấu hai chấm `:` và kết thúc bằng dấu chấm phẩy `;`.

    ```text
    bo_chon {
      thuoc_tinh_1: gia_tri_1;
      thuoc_tinh_2: gia_tri_2;
    }
    ```

    *Ví dụ 1: Định dạng chữ đỏ cho tất cả tiêu đề `<h1>`:*
    ```css
    h1 {
      color: red;
    }
    ```

    *Ví dụ 2: Nhóm nhiều bộ chọn lại với nhau (ngăn cách bởi dấu phẩy `,`):*
    ```css
    h1, h2, h3 {
      border: 2px solid red;
      font-family: Arial, sans-serif;
    }
    ```

    ### 4. Ý nghĩa và vai trò then chốt của CSS

    1. **Tách biệt nội dung và hình thức:** Giúp người lập trình tập trung vào cấu trúc nội dung khi viết HTML, sau đó chuyên tâm tinh chỉnh mỹ thuật bằng CSS mà không làm xáo trộn dữ liệu.
    2. **Tiết kiệm thời gian và tài nguyên:** Tệp CSS ngoài được trình duyệt tải về và lưu vào bộ nhớ đệm (Cache). Khi người dùng chuyển qua các trang tiếp theo trong website, trình duyệt không cần tải lại kiểu dáng nữa, giúp trang web mở nhanh tức thì.
    3. **Tính nhất quán cao:** Đảm bảo toàn bộ hệ sinh thái website có cùng một bộ nhận diện thương hiệu về màu sắc, phông chữ và bố cục.
    4. **Dễ bảo trì và nâng cấp:** Khi muốn "thay áo mới" cho toàn bộ website, lập trình viên chỉ cần chỉnh sửa một tệp CSS duy nhất.

    ### 5. Câu hỏi củng cố (Trang 74–75 SGK)

    **Câu 1:** *Nếu muốn tất cả các đoạn văn bản của trang web có màu xanh (blue) thì cần thiết lập định dạng CSS như thế nào?*
    ```css
    p {
      color: blue;
    }
    ```

    **Câu 2:** *Giải thích ý nghĩa của mẫu định dạng CSS sau: `h1, h2, h3 { border: 2px solid red; }`*
    - Mẫu CSS này áp dụng đồng thời cho cả ba loại thẻ tiêu đề: `<h1>`, `<h2>`, và `<h3>`.
    - Thiết lập đường viền (`border`) bao quanh các phần tử này là **nét liền (`solid`)**, có **độ dày 2 pixel (`2px`)** và có **màu đỏ (`red`)**.
  </RawContent>
  <TeacherNotes>
    **Gợi ý sư phạm:**
    - So sánh với tính năng **Styles** trong Microsoft Word (Heading 1, Heading 2, Normal): Khi sửa định dạng của một Style trong Word, mọi đoạn văn bản gắn với Style đó lập tức đổi theo. CSS hoạt động với tư duy tương tự nhưng mạnh mẽ và linh hoạt hơn nhiều.
  </TeacherNotes>

<StepPractice title="3. Luyện tập thực hành (Practice)">
  <RawContent>
    ### Luyện tập 1 & 2 (Trang 75 SGK)

    **Câu 1:** *Ngôn ngữ định dạng CSS chính là ngôn ngữ HTML, đúng hay sai?*  
    👉 **Sai.** CSS và HTML là hai ngôn ngữ độc lập với cú pháp, vai trò và chuẩn kỹ thuật hoàn toàn khác nhau. HTML là ngôn ngữ đánh dấu siêu văn bản, còn CSS là ngôn ngữ quy định bảng kiểu trình bày.

    **Câu 2:** *Khẳng định sau là đúng hay sai: "Có thể chỉ cần thay đổi thông tin của một tệp CSS sẽ làm thay đổi định dạng của nhiều trang web, thậm chí cả một website"?*  
    👉 **Đúng.** Đây chính là sức mạnh vượt trội của phương pháp **CSS ngoài (External CSS)** khi nhiều tệp HTML cùng liên kết đến một tệp `.css` duy nhất.

    ---

    ### Thực hành mẫu: Thiết lập trang web tích hợp CSS 3 cấp độ

    Tạo thư mục dự án gồm 2 tệp:
    1. Tệp kiểu dáng ngoài `mystyle.css`:
    ```css
    /* Tệp định dạng CSS dùng chung */
    body {
      font-family: Arial, sans-serif;
      background-color: #f8fafc;
      margin: 20px;
    }

    h1 {
      color: #0284c7;
      border-bottom: 2px solid #0284c7;
      padding-bottom: 6px;
    }

    p {
      color: #334155;
      line-height: 1.6;
      text-indent: 20px;
    }
    ```

    2. Tệp trang web `index.html`:
    ```html
    <!DOCTYPE html>
    <html lang="vi">
    <head>
      <meta charset="UTF-8">
      <title>Minh họa 3 phương pháp nhúng CSS</title>
      <!-- 1. CSS ngoài -->
      <link rel="stylesheet" href="mystyle.css">

      <!-- 2. CSS trong -->
      <style>
        .highlight {
          background-color: #fef08a;
          padding: 8px 12px;
          border-radius: 6px;
        }
      </style>
    </head>
    <body>
      <h1>Khái niệm và vai trò của CSS</h1>
      <p>
        CSS giúp định nghĩa phong cách trình bày cho các phần tử trên trang web.
      </p>
      
      <!-- 3. CSS nội tuyến -->
      <p class="highlight" style="color: #b91c1c; font-weight: bold;">
        Đoạn văn này vừa nhận kiểu từ CSS ngoài, vừa có nền vàng từ CSS trong, và chữ đỏ từ CSS nội tuyến!
      </p>
    </body>
    </html>
    ```
  </RawContent>
  <TeacherNotes>
    **Hướng dẫn học sinh:**
    - Chú ý quan sát sự kết hợp xếp tầng (Cascading) của CSS: Một phần tử có thể nhận đồng thời các thuộc tính từ CSS ngoài, CSS trong và CSS nội tuyến.
  </TeacherNotes>
</StepPractice>
